# v0.1.29

## Harness 0.2.1-rc.2 support

A host upgraded from `0.2.1-alpha.2` to the published `0.2.1-rc.2` cohort denied this plugin at profile startup: none of the 21 `@deepseek-ai/dsh-*` peer ranges listed the new runtime version. `0.2.1-rc.2` is now declared in `compatibility.json` (track `preview`; eleven declared targets) and enumerated in every host peer range, so the loader admits the plugin again. The recommended host remains `0.2.0-rc.2`.

The shared-runtime cohort moved to stable releases: `@deepseek-ai/cordis@4.0.5` and `@deepseek-ai/schemastery@3.18.5` are now ordinary versions, so the plugin's existing `^4.0.2` / `^3.18.2` ranges match them without widening (the alpha-era `|| 4.0.5-alpha.x` / `|| 3.18.5-alpha.x` alternatives stay for the older cohorts).

## API review against 0.2.1-rc.2

Every surface this plugin drives was re-checked against the installed rc.2 packages and is present:

- Subagent lifecycle: `startActivation(spec)` (with the `delivery` field), `drainChildren(parent, childIds)`, `sendMessage(sender, targetId, content, options)`, `interrupt(targetSessionId, authority)`, provider `prepareContinuable` + `capabilities.persona`/`toolFilter`, and `Symbol.for('dsh.subagent.deliverPrompt')` — the alpha.2 adaptation in `src/harness-compat.ts` (`startContinuableChild`, `drainTeamMemberChildren`) applies unchanged. `registerContinuableSetup` remains absent (the 0.1.2 legacy path stays guarded off).
- Agent events: `agent/created`, `agent/pre-step`, `agent/status`, `agent/request-error`; `Agent.followup` for command gestures.
- Tool registry: `defineTool`, `ctx.tools.register`, `tools.restrict()` with `view().restrictableNames`.
- Client: `uiWorkspace.openSession`, `layout.selectPanel`/`beginNavigation`, the sidebar-right packages, and all eight injected client packages.

No source change beyond the compatibility manifests was required; the plugin's host seam was already at the modern generation.

Verified with `node scripts/compatibility.mjs`, `node scripts/readme-version.mjs`, `node scripts/release-metadata.mjs`, `pnpm typecheck`, `pnpm test` (71 tests), and the 0.2.1-rc.2 runtime matrix run (`scripts/harness-runtime-verify.mjs --host-version 0.2.1-rc.2`); packaged as `0.1.29`.
