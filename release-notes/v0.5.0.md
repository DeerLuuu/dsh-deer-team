# v0.5.0

## Deer theme, dashboard layout, and the new repository

The plugin now lives at [DeerLuuu/dsh-deer-team](https://github.com/DeerLuuu/dsh-deer-team).

### Character artwork replaces the whale set

- Three characters ship in `assets/deers-agent-team/` in three variants each: full illustration, paper cutout and sticker.
  - **Deer** — the captain, stamping approvals.
  - **Panda** — builders, data and operations roles.
  - **Cat** — research, design, QA, security and review roles.
- Role keywords resolve to one of the three cutouts; the captain is always the deer. The conversation card uses compact stickers; the activity panel uses paper cutouts.
- The whale role/action artwork and its allowlist entries were removed. `scripts/verify.mjs` now checks the nine character assets, their real PNG/WebP headers, and the three-character mapping.
- README/README_ZH use a new character banner (`assets/readme/team-characters.png`) instead of the old whale-era screenshot.

### DeerSuperGroup-style team layout

- **Topbar**: team name, phase pill (running / planning / paused), member/task/message counters and actions (polls, stop) in a card header.
- **Summary card**: team progress, delivery-rate ring, and four status tiles — in progress / queued / waiting on dependencies / delivered — above the segmented task bar and the human-readable summary.
- **Members card**: the captain row now sits inside the members card, followed by the collapsible roster with character avatars, model badges, assignment chips and mailbox actions.
- **Task star map**: the dependency graph is presented as a star map card with a starfield background, rounded glass task nodes, zoom/fit controls, minimap, task filter chips and a task-count badge. The resizable members / star-map split remains in wide workspace panes.
- All colors still come from host semantic tokens, so light and dark themes keep working.
