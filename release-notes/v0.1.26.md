# v0.1.26

## Workspace layout: draggable column separator, edge-to-edge columns

The workspace team view (团队协作 tab) renders the delegation tree and the dependency map side by side on wide panes. Two requested layout improvements:

- **Draggable separator (Godot-style).** A dedicated separator now sits between the two columns: a 2 px line that widens and takes the business accent color on hover/focus/drag, with `col-resize` cursor and pointer capture. Dragging sets the left column width live (clamped to 22–78% of the section, 260 px floor preserved by the grid track); the ratio persists in `localStorage` (`deers-agent-team.workspace-split`) and survives panel re-mounts. The separator is a real `role="separator"` control: ←/→ nudge by 1.5% (Shift ×3.3), Home resets to the default 38.5%, and the label ships in both UI languages through the host locale service. It replaces the old painted `border-left` on the dependency section, renders only on panes ≥1000 px (below that the layout stays single-column), and is hidden in the staged-plan editor layout, which keeps its own equal split.
- **Columns fill the pane.** The workspace content wrapper's `max-width: 1400px; margin: 0 auto` centered the view and left blank gutters on wide panes; the content now spans the full pane width so both columns (and the separator) use all available space. Padding remains as breathing room.

Client-only change (`ActivityPanel.tsx`, both CSS modules, two locale keys); no tool, protocol, or state changes. Verified with `pnpm typecheck`, the full unit suite (71 tests), and the `scripts/verify.mjs` source gate; packaged as `0.1.26`.
