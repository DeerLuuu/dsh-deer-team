# v0.3.0

## New: team polls with a dedicated floating voting window

Formal team voting no longer lives in the blackboard. Polls are a separate durable store with explicit options, one ballot per participant, single- or multi-choice modes, and an explicit close step. A dedicated floating window, opened from the team header, lets the human create and join a vote without expanding the activity panel.

### Poll tools

| Tool | Behavior |
| --- | --- |
| `deers_team_vote_create` | Captain only. 2-10 unique options; single-choice by default, `multi_select: true` for multi-choice with optional `max_selections`; optional `description` and `duration_minutes` deadline. |
| `deers_team_vote_cast` | Every participant. `option_ids` must match the mode (1 for single-choice, up to the cap for multi-choice); `[]` withdraws the ballot. Each participant has one ballot poll-wide. |
| `deers_team_vote_read` | Every participant. Tallies per option with voter names, total voters, own ballot; read one poll via `poll_id` or filter by `status` (`open` / `closed` / `expired`). |
| `deers_team_vote_close` | Captain only, idempotent. Closed polls keep tallies and reject new ballots. |

### Storage and rules

- Polls live in `team.json` under `polls` (`{ seq, polls }`), up to 50 retained; option labels are bounded, and malformed persisted polls are normalized instead of failing the team record.
- Single-choice ballots accept at most one option; multi-choice ballots respect `maxSelections` (default: every option).
- A deadline makes an open poll report `expired` and reject late ballots.
- Polls are summarized in `deers_team_digest` (open count, voters, leading options) and in `deers_team_status`.

### Dedicated floating window

- The team section header now has a 🗳 button. It opens an independent poll window (fixed bottom-right, closable) registered in `shell.overlay`, so it stays usable while the activity panel is folded or the conversation scrolls.
- The window lists polls with per-option counts and voter names, lets the human vote/clear/close as the captain, and has a create form for single- or multi-choice polls (options one per line, optional max selections and duration).
- It uses the authenticated `/plugins/deers-dsh-agent-team/polls` route; historical archives stay out of the flow (the button is only shown for live teams).

### Blackboard separation

The blackboard keeps its informal up/down reactions, but the tool description and the captain protocol now say formal votes must use polls. Brainstorming still uses the board; decisions use a poll.
