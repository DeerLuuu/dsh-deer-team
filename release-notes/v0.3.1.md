# v0.3.1

## Fix: the poll window opens on records, not the creation form

The v0.3.0 floating window showed the "start a poll" form first, so opening it on a team with existing votes looked like a create dialog rather than a history panel.

- The poll window now opens on **poll records**: every poll is listed newest-first (open, closed and expired), with per-option counts, voter names, status, mode and total voters.
- Filters: **All / Open / Closed** (closed includes expired), with an empty-filter hint.
- The creation form moved behind a **+ Start a poll** toggle; the list stays the primary view. Closing the form returns to the records list.
- Archived teams now expose the same vote button (read-only window: results without voting controls), so historical poll records stay reachable.
- The team header button is now a labeled `🗳 Polls` control instead of an unlabeled icon.
- The standalone panel page (`/deers-agent-team/`) gained a **Polls** section that renders the same durable polls with counts and voter names.

## Change: team member cap is now 12 by default

`maxMembers` default changed from 8 to 12 in both the Config schema and the resolved tool config. Profiles and explicit `maxMembers` values are unchanged; this only moves the default cap.

## Verification

- `pnpm typecheck` passes.
- 103 unit tests pass (the standalone page test now asserts the Polls section; the poll state/tool tests are unchanged).
- Build and pack succeed; the package is installed on the profile.
