# v0.4.0

## Polls as decisions, modeled on DeerSuperGroup

Team polls already had single/multi choice, deadlines and ballot storage. This release turns them into auditable decisions aligned with the DeerSuperGroup poll design:

- **Adoption rule**: `majority` (default), `gt` (absolute vote count) or `percent` (share of ballots). Configured as `threshold_rule` / `threshold_value`.
- **Quorum**: a minimum number of ballots before any option can be adopted (`quorum`, default 1).
- **Decision on close**: closing evaluates every ballot once and freezes a `decision` with adopted options, insufficient-quorum flag, totals, rule, summary, timestamp and closer. Closing stays idempotent.
- **Ballot revisions**: every submission, change or withdrawal increments the voter's revision; the read result returns `myRevision` and the ballot's voter type (`captain` human seat vs `member` Agent).
- **Anonymous display**: `anonymous: true` hides voter names in reads and the panel while the durable ballot and audit metadata stay in team state.
- **Visibility**: `deers_team_vote_read`, `deers_team_status`, the digest, the floating poll window and the standalone `/deers-agent-team/` page all show the rule, quorum, tallies and the frozen decision.

### Tools

| Tool | Change |
| --- | --- |
| `deers_team_vote_create` | New `threshold_rule`, `threshold_value`, `quorum`, `anonymous` parameters; output echoes the rule and quorum. |
| `deers_team_vote_cast` | Returns the ballot `revision`; withdrawals keep the revision history. |
| `deers_team_vote_read` | Renders rule/quorum/anonymity and the decision for closed polls. |
| `deers_team_vote_close` | Returns `adopted`, `insufficient_quorum` and the decision `summary` in addition to status. |

### Panel

- The floating window's create form now offers the adoption rule, threshold value (for `gt`/`percent`), quorum and anonymous display.
- Poll cards show the rule and quorum, hide voter names when anonymous, and render the decision banner (adopted options or no adoption/quorum warning) after close.
- The standalone page renders the same rule/quorum/anonymity/decision metadata.
