# v0.1.27

## Progress overview wrapping and a panel-wide font boost

Two requested readability changes, both client-only:

- **Progress overview wraps.** The total-progress strip squeezed every task into one flex row, so beyond roughly 30 tasks each segment collapsed towards zero width. Segments now render 30 per row and the strip wraps into as many rows as needed (two, three, more), each row keeping the full-width, evenly distributed layout. Counts and colors are unchanged (`progressSegmentRows` is a plain grid wrapper around the existing per-row strips).
- **Panel-wide font boost (+2px).** Every fixed-px `font-size` and `line-height` in the panel module (127 declarations) now computes as `calc(Npx + var(--deers-font-boost))`, with `--deers-font-boost: 2px` set on the two surfaces (workspace root and floating panel) — every text tier (10px captions through 15px headings) grows by exactly 2px, and unitless line-heights scale with it. Revert or tune later by changing that one variable on `.root`/`.panel` (set `0px` to go back). The workspace content wrapper (`WorkspaceActivity.module.css`) carries the same six declarations.

No tool, protocol, or state changes. Verified with `pnpm typecheck`, the full unit suite (71 tests), and the `scripts/verify.mjs` source gate; packaged as `0.1.27`.
