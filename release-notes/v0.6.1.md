# v0.6.1

## Fix: native dropdown options were unreadable on Windows

The blackboard author/group/kind selects (and every other native `<select>` in the plugin) opened a white system menu while the option text inherited the dark-theme light label colour, so names appeared nearly invisible.

- Every plugin select now styles its `option` / `optgroup` with explicit theme colors (`--dsw-alias-bg-layer-1` background, `--dsw-alias-label-primary` text):
  - blackboard author / grouping / kind selects,
  - poll adoption-rule select,
  - task reassign select and staging-plan selects,
  - workspace team selector.
- The standalone `/deers-agent-team/` page sets its option/optgroup colours explicitly for its dark palette.

No behavior change beyond the dropdown colours. Verified with `pnpm typecheck`, 112 tests, `scripts/verify.mjs`, build and profile activation.
