# v0.2.2

## Fix: recall must not read other participants' mailboxes

`deers_team_recall` searched every mailbox when resolving a `message_id`, so a member who knew (or guessed) a message id could read a message addressed to another member or to the captain. That contradicted the status tool's visibility rule (captain sees every inbox; a member sees only its own).

The recall tool now resolves owners exactly like `deers_team_status`: the captain may recall any inbox, a member may recall only its own mailbox. Tasks and blackboard entries remain team-wide reads.

Verified: `pnpm typecheck`, 95 unit tests (new: captain can recall a captain-inbox message; a member gets "not found" for the captain's or another member's message), build, and a fresh install on the profile.

The rest of the v0.2 line is unchanged; see `v0.2.0` for the watchdog/Router-role/digest/progress/batching release and `v0.2.1` for the watchdog timer fix.
