# v0.1.28

## Panel: task operations, mailbox, timeline, history, filters, team switcher, DAG zoom

Eight workspace-panel features, one client+route release. All task/mail operations reuse the existing captain authorization pattern (`sessionId` → live captain agent → `findTeamByCaptain`), and all reads derive from durable state, so they work for archived teams too where noted.

- **Multi-team switcher.** With more than four teams for one session the pill row becomes a grouped dropdown (live teams / archived), styled to match.
- **Persistent view states.** The member-tree collapse and the dependency-map open state now persist per team in `localStorage` (`deers-agent-team.view.*`).
- **Task operations.** The task detail panel offers 取消任务 / 重新派发 / 改派成员 (with a member dropdown or shared pool/captain). Backed by a new `POST /task-op` route over a new `runTaskOperation` runtime bridge: cancel stops the owner member's activation so the revoked attempt stops burning turns; redispatch revokes the attempt, drains the member and requeues; reassign validates the busy/dependency rules from `reassign_task` for pending tasks and kicks the scheduler. Destructive ops confirm first.
- **Member mailbox.** Every member row (and the captain node) gets a ✉ button opening a mailbox modal: durable non-discarded messages oldest-first (new `GET /mail` route), plus a compose box that sends as the captain through a new `sendCaptainMailboxMessage` runtime bridge — same delivery path as the `send_message` tool (steer-wake, mailbox fallback). Captain mailbox is read-only; archived teams are read-only.
- **Activity timeline.** A collapsible full-width section derives a newest-first timeline from durable state only — member joins, task creations, latest task transitions, mailbox traffic — via `GET /timeline`. No new persistence, so it works retroactively for every team including archives.
- **Task attempt history.** The task detail shows the attempt generation and a 历史/证据 block backed by `GET /history`: contract revisions (the amend ledger), supplemental evidence entries, final output, and open findings.
- **Failed/blocked one-click filter.** Filter chips (全部/运行中/阻塞/失败/已完成) in the dependency header dim non-matching DAG nodes and member rows.
- **DAG zoom, pan and minimap.** The dependency canvas (non-parallel layout) is now a real viewport: wheel zooms around the cursor (0.35×–2.5×), background drag pans, a corner minimap with per-state node colors and a viewport rectangle jumps the view, and −/%/+/适应 controls sit on the canvas. The parallel grid and the staged editor keep their layouts.

New snapshot field: `task.attempt`. New routes: `task-op`, `mail`, `message`, `timeline`, `history` (all behind `authenticatedWebRoutes`). Verified with `pnpm typecheck`, the full unit suite (71 tests) and the `scripts/verify.mjs` source gate; packaged as `0.1.28`. Also fixes v0.1.27's font-boost CSS regression before it shipped to a reload (the values are restored and the boost reapplied correctly).
